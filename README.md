## Stack

Next.js (App Router), TypeScript, Tailwind, Framer Motion. Contact form via Resend when `RESEND_API_KEY` is set.

## How to run

```bash
npm install
cp .env.example .env.local   # add RESEND_API_KEY if using email
npm run dev
```

Open http://localhost:3000
